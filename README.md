# DocVerse

DocVerse is a modern web application for editing, converting, compressing, merging, and securing PDF documents.

## Features

- Merge PDF
- Split PDF
- Compress PDF
- JPG to PDF
- PDF to JPG
- Password Protection
- OCR (Coming Soon)

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Node.js
- Express
- Firebase Authentication
- Firestore
- Vercel
- Render
